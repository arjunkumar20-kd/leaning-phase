# Roast & Ritual

A front-end learning project focused on building a premium coffee-brand landing page and practicing HTML, CSS, and JavaScript fundamentals.

## Overview

This repository contains a polished landing page for a fictional coffee brand called Roast & Ritual, along with multiple assignment files used for front-end practice and experimentation.

The project is designed to showcase:

- responsive page layouts
- semantic HTML structure
- customized styling and typography
- JavaScript-driven interactivity
- animation and motion design
- beginner-to-intermediate front-end learning exercises

## Language Composition

This repository is primarily built with:

- HTML: 64%
- CSS: 25.8%
- JavaScript: 10.2%

## Features

- Responsive coffee landing page for desktop and mobile screens
- Branded hero section with strong calls to action
- Story, menu, bakery, and visit sections
- Interactive roast intensity control and dynamic UI behavior
- GSAP-powered animations and smooth hover effects
- Reduced-motion support using `prefers-reduced-motion`
- Practice files covering HTML, CSS, and JavaScript fundamentals

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- Google Fonts

## Run Locally

Because this is a static front-end project, there is no build step required.

### Option 1: Open the page directly

1. Clone the repository:

```bash
git clone https://github.com/arjunkumar20-kd/leaning-phase.git
cd leaning-phase
```

2. Open `index.html` in a browser.

### Option 2: Use a local server

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
